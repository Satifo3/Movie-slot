# MOVIE v6 — Image Skin UI

- ホーム画面の見た目は参考画像そのもの
- SPINボタンと下部ナビの位置に透明な操作領域を重ねる
- スロット回転中だけ3リール部分にアニメーションを重ねる
- 結果が出たら、参考画像の結果カード位置に動的HTMLカードを重ねる
- 300タイトルDB / AND条件抽選 / 観たい / 視聴履歴 / S-A-B-C評価は維持
- GitHub Pages対応
