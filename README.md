## v6.10 スロット仕様
- 7種類の揃いパターン
  - 上段横一列
  - 中段横一列
  - 下段横一列
  - 右下がり斜め
  - 右上がり斜め
  - V字
  - 逆V字
- 左 → 中央 → 右の時間差停止
- 揃った後に WIN 演出
- 停止したリール結果は消さず、次のSPINまで保持
- 結果カードが表示されてもリールはそのまま残る
