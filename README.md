# MOVIE v6.7 — Stable UI Fix

今回の修正は見た目の調整ではなく、動作停止の原因から直しています。

## 重大バグ修正
- `app.js` 内に `const reelSymbols` が2回宣言されていた構文エラーを修正
- このエラーのせいでJavaScript全体が停止し、SPIN / ナビ / 設定 / 履歴など全ボタンが反応しない状態でした
- ナビゲーションを透明ホットスポット方式から、実際のHTMLボタン方式へ変更
- 画面遷移時のactive状態もJavaScriptで同期

## 観たいリスト通知
- JPEGに焼き込まれた古い通知部分は、ナビ全体を不透明HTMLで完全に覆う方式に変更
- 0件 = バッジ完全非表示
- 1件 = 1
- 2件 = 2
- 実際のlocalStorage件数と同期

## 検証
- 300タイトルDB維持
- No-Fetch維持
- `MOVIE_SELF_TEST()` を追加し、必須ボタン/画面/DB件数を起動時に検証
